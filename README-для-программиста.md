# Prom-Test CRM — новый стиль

В папке два варианта. Их можно внедрять по очереди.

## Вариант 1. Быстро: новый стиль для старого `crm.php` (1 строка)

**Файл:** `promtest-new.css`

1. Положить файл в `p110/css/promtest-new.css`.
2. В `<head>` файла `crm.php` добавить строку **после** `crm.css`:

   ```html
   <link rel="stylesheet" type="text/css" href="css/promtest-new.css">
   ```

HTML, PHP и JS менять не нужно. Файл перекрашивает существующую разметку:

- верхнее меню `#tbb`: компактные кнопки, CRM выделен фиолетовым, «Выход» стоит справа;
- три колонки: «Незавершенные визиты», календарь, «Незавершенные мероприятия»;
- вкладки «Индивидуальный визит / Мероприятие»;
- FullCalendar 3: кнопки, сегодняшний день, выходные, события;
- формы визита и мероприятия, кнопки «Завершить / Удалить», jQuery UI datepicker.

**Просмотр:** откройте `crm-promtest-preview.html`. Это сохранённая страница с подключённым новым CSS. Bootstrap и FullCalendar в ней грузятся с CDN, а скрипты не работают, это только просмотр.

**Желательно поправить в PHP:**

- В пунктах меню убрать `<br>` («Заказы<br>Old», «Добавить<br>пользователя» и т.п.), тогда кнопки будут в одну строку.
- Исправить кодировку в базе. Часть текста записана как UTF-8, прочитанный как cp1252 (например, `Ð“Ð¾Ñ€Ð¼Ð¾Ð½Ñ‹` вместо «Гормоны»). Исправить можно так: `CONVERT(CAST(CONVERT(col USING latin1) AS BINARY) USING utf8mb4)`. Сначала проверить на копии таблицы! И проверить, что соединение с MySQL открывается с `SET NAMES utf8mb4`.
- Незавершённые визиты 2019–2020 годов закрыть или перенести в архив.

## Вариант 2. Новый интерфейс CRM

**Стартовая страница:** `index.html` (дизайн как у promtest-events: логотип, глобус, ближайшие визиты и мероприятия, логотипы компаний). Стили: `crm-home.css` + `crm-new.css`, картинки `logo.png`, `logos/`.
Кнопка «Ընդհանուր →» ведёт в `general.html` — все визиты, мероприятия и участие на 7 дней, начиная с сегодняшнего дня (выбор дат «Սկսած / Մինչև» до 62 дней, быстрые 7/14/30 дней, ‹ › листают на тот же период, фильтры по типам и по сотрудникам).
Кнопка «Մասնակցություն» ведёт в `participation.html` — страницу участия в мероприятиях из promtest-events (файлы `participation.*`, данные `promtest-events-v1`); Форма участия открывается кнопкой «+ Նոր միջոցառում» на самой странице `participation.html`.
Остальные кнопки ведут в `vizit.html`, `vizit.html#new` (новый визит), `vizit.html#new-event` (новое мероприятие — кнопка «+ Նոր միջոցառում» на главной).


**Файлы:** `index.html`, `crm-home.css`, `vizit.html`, `crm-new.css`, `crm-new.js`, `logo.png`, `logos/`

`vizit.html` можно открыть в браузере, он работает сразу. Данные хранятся в `localStorage` этого браузера.

Что в нём есть:

- вкладки «Անհատական այց» (визит) и «Միջոցառում» (мероприятие);
- сводка;
- фильтр по менеджерам;
- календарь в центре: клик по дню открывает форму с этой датой, клик по записи открывает её;
- список по месяцам;
- редактируемые списки;
- экспорт в CSV.

### Как подключить к сайту

В `crm-new.js` весь доступ к данным собран в нескольких функциях. Их нужно заменить на AJAX к PHP:

| Функция | Что делает | PHP |
|---|---|---|
| `useLocal()` / `init()` | загрузка всех записей и списков | `GET crm_api.php?a=list` → `{visits:[…], lists:{…}}` |
| `saveVisit(o)` | создать / изменить запись | `POST crm_api.php?a=save` (JSON) → `{id}` |
| `removeVisit(id)` | удалить | `POST crm_api.php?a=delete&id=…` |
| `saveLists(next)` | сохранить справочники | `POST crm_api.php?a=lists` |

После ответа сервера нужно обновить массив `visits` и вызвать `render()`.

### Поля записи (одна таблица `crm_visits`)

| Поле | Тип | Визит | Мероприятие | Примечание |
|---|---|---|---|---|
| `id` | varchar / int | ✓ | ✓ | |
| `kind` | `visit` \| `event` | ✓ | ✓ | |
| `date` | DATE (`YYYY-MM-DD`) | ✓ | ✓ | обязательно |
| `time` | varchar(5) | ✓ | ✓ | |
| `rep` | varchar | ✓ | ✓ | менеджер, лучше id из `users` (сейчас Армине 486, Лусине 484, Анна 3, Анна Ш. 162, Анаит 488, Сируш 412, Вардан 1005) |
| `clinic` | varchar | ✓ | ✓ | для мероприятия: место |
| `doctors` | text | ✓ | | врачи, по одному на строку |
| `tests` | JSON / text | ✓ | ✓ | массив названий тестов |
| `topic` | text | ✓ | ✓ | Тема |
| `agreement` | text | ✓ | | Договоренность |
| `objections` | JSON / text | ✓ | | массив возражений |
| `etype` | varchar | | ✓ | Круглый стол / Презентация / Конференция / Вебинар; обязательно |
| `ename` | varchar | | ✓ | название |
| `speaker` | varchar | | ✓ | спикер |
| `participants` | int | | ✓ | число участников |
| `notes` | text | ✓ | ✓ | |
| `status` | `open` \| `done` | ✓ | ✓ | соответствует кнопке «Завершить» |

Статус на экране вычисляется по полям `status` и `date`:

- `done` → «Ավարտված» (зелёный);
- дата в будущем → «N օր հետո»;
- сегодня → «Այսօր»;
- дата в прошлом и `open` → «Ուշացած» (красный).

## Структура страниц (актуально)

| Страница | Файлы | Данные (localStorage) |
|---|---|---|
| Главная | `index.html`, `home.css`, `base.css`, `logo.png`, `logos/` | читает все |
| Ընդհանուր | `general.html`, `base.css` — список по дням, строками (время · тип · фирма · название · сотрудник · логотип) | читает все |
| Այց | `vizit.html`, `vizit.css`, `vizit.js` | `promtest-visits-v1` (`kind: visit`) |
| Միջոցառում | `mijocarum.html`, `mijocarum.css`, `mijocarum.js` | `promtest-visits-v1` (`kind: event`) |
| Մասնակցություն | `masnakcutyun.html`, `masnakcutyun.css`, `masnakcutyun.js`, `masnakcutyun-data.js` | `promtest-events-v1` |

У каждой страницы свой календарь и своя форма («+ Նոր …» или клик по дню). `vizit.js` и `mijocarum.js` отличаются строкой `const PAGE="visit"|"event"`.
Старые имена (`crm-new.*`, `crm-home.css`, `participation.*`) больше не используются.
